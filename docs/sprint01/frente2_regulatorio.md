# Frente 2 – Base Regulatória e Técnica

## Introdução

A implementação de sistemas de carregamento compartilhado deve respeitar regulamentações do setor elétrico e considerar as especificações técnicas dos equipamentos utilizados.

---

# Resolução Normativa ANEEL nº 1000/2021

A Resolução Normativa nº 1000/2021 estabelece as condições gerais para fornecimento de energia elétrica no Brasil.

## Aspectos Relevantes

- Segurança elétrica
- Medição adequada do consumo
- Transparência tarifária
- Conformidade da instalação
- Responsabilidade dos usuários

A norma permite que empreendimentos realizem controle individualizado do consumo energético.

# API GoodWe SEMS Portal

A API SEMS Portal fornece dados operacionais dos carregadores.

## Dados Disponíveis

- Histórico de sessões
- Potência instantânea
- Energia consumida
- Status operacional
- Alarmes e eventos

## Aplicação no Projeto

Os dados serão utilizados para:

- Alimentação do banco de dados
- Monitoramento em tempo real
- Geração de relatórios
- Aplicação de inteligência artificial
